# VOLT//KIN — Game Design Bible

## Identity
Adventure/collection RPG about customizable machine/creature partners, evolution/fusion, elemental systems and a strong sense of discovery. Machines should feel like characters and engineered builds simultaneously.

## Core loop
Explore → encounter/challenge/recover Kin → battle → salvage parts/data → bond/tune/evolve/fuse → solve traversal/puzzle obstacles → story/faction choices → unlock new regions/build possibilities.

## Kin system
Species/chassis identity, core affinity, attributes/elements, modular parts, abilities, passive traits, bond/personality, evolution branches, fusion/inheritance and cosmetic/mechanical expression. Parts have compatibility and meaningful tradeoffs.

## Combat
Action/strategic hybrid selected through playtesting; Action RPG Multiplayer Combat and Element Reaction System are Unreal accelerators. Player skill, team composition and engineering decisions must all matter.

## Exploration
Traversal abilities from Kin unlock shortcuts/secrets. World contains towns, facilities, wild zones and machine ruins.

## Progression
Player tools + Kin roster + parts + evolution/fusion + faction/research knowledge. Avoid pure vertical-stat treadmill.

## V1→V3
V1 proves one region, representative Kin roster, customization/evolution/fusion, combat and traversal. V2 expands world/factions/multiplayer/build ecosystem. V3 completes campaign/endgame/collection and AXIOM-native implementation.
